# 🩺 Medical Clinical Decision Support System — Rule-Based Expert Engine

[![Python](https://img.shields.io/badge/python-3.13-blue.svg)](https://www.python.org/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.141-green.svg)](https://fastapi.tiangolo.com/)
[![Docker](https://img.shields.io/badge/docker-✓-blue.svg)](https://www.docker.com/)
[![Streamlit](https://img.shields.io/badge/Streamlit-UI-orange.svg)](https://streamlit.io/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Система поддержки принятия клинических решений** на основе правил. Анализирует лабораторные данные и выдаёт структурированное заключение с диагнозами, рекомендациями, оценкой риска и детальными клиническими инсайтами (шпаргалкой для врача).

> **English:** Rule-based clinical decision support system for laboratory data analysis with structured conclusions, recommendations, risk assessment, and detailed clinical insights (cheat sheet for clinicians).

---

## ✨ Ключевые возможности

- 🧪 **Парсинг лабораторных данных** – поддержка алиасов (рус/англ) и автоматическая конвертация единиц
- 🩺 **50+ клинических правил** – анемии, диабет, почки, печень, инфекции, метаболические нарушения
- ⚥ **Половозависимые пороги** – разные референсные интервалы для 10+ параметров (Hb, креатинин, АЛТ, АСТ, ГГТ, ферритин, железо, эритроциты, гематокрит, СОЭ)
- 🔗 **Комбинированные диагнозы** – синдромы на основе нескольких находок (первичный гиперпаратиреоз, септический синдром)
- 📋 **Структурированное заключение** – группировка по системам органов, дедупликация, описания
- 🧠 **Клинические инсайты** – подробная интерпретация: критерии, дифференциальная диагностика, красные флаги, шпаргалка по тактике, ссылки
- 👨‍⚕️ **Рекомендации** – специальности, срочность, дополнительные тесты
- 📊 **Хранение истории** – SQLite с возможностью загрузки последнего отчёта по ID пациента
- 🔐 **JWT-аутентификация** – роли: `admin`, `doctor`, `user`
- 🖥️ **Современный веб-интерфейс** – Streamlit с автодополнением, цветовой индикацией риска, интерактивными карточками
- 📄 **Экспорт в PDF** – заключение с поддержкой кириллицы
- 🔄 **Горячая перезагрузка конфигурации** – обновление правил без перезапуска контейнера
- 🐳 **Docker-контейнеризация** – запуск одной командой

## 🏗️ Архитектура

Проект следует принципам **чистой архитектуры** с чётким разделением ответственности:
medical_ai1/
├── domain/ # Чистое ядро (сущности, value objects, бизнес-логика)
├── application/ # Сценарии использования и порты (интерфейсы)
│ └── services/ # Сервисы (интерпретатор, пост-процессор)
├── infrastructure/ # Адаптеры (загрузчики, парсеры, хранилище, DI)
│ ├── adapters/
│ │ ├── loaders/ # Загрузчики YAML-конфигураций
│ │ ├── parsers/ # Парсер лабораторных данных
│ │ ├── renderers/ # Рендереры отчётов
│ │ └── storage/ # SQLite-репозитории
│ └── bootstrap/ # DI-контейнер
├── api/ # REST API (FastAPI, аутентификация)
├── knowledge/ # Конфигурации в YAML
│ ├── configs/ # Пороги, логика, интерпретации, рекомендации
│ ├── guidelines/ # Клинические правила
│ └── laboratory/ # Алиасы и единицы измерения
├── tests/ # Юнит- и интеграционные тесты
├── docs/ # Документация
├── fonts/ # Шрифты для PDF
├── streamlit_app.py # Веб-интерфейс (Streamlit)
└── docker-compose.yml # Запуск API + UI одной командой

### Технологический стек

| Слой | Технология |
|------|------------|
| **Ядро** | Python 3.13 |
| **Веб-API** | FastAPI + OpenAPI (Swagger) |
| **Валидация** | Pydantic |
| **Конфигурация** | PyYAML |

| **Контейнеризация** | Docker, Docker Compose |

## 🚀 Быстрый старт

### Запуск с Docker (рекомендуется)

```bash
git clone https://github.com/9577030-png/MedCDSS-RB.git
cd MedCDSS-RB
docker-compose up -d
После запуска:

API документация: http://localhost:8000/docs

Streamlit интерфейс: http://localhost:8501

Учётные записи по умолчанию:

Логин	Пароль	Роль
admin	admin	Администратор (полный доступ)
doctor	doctor	Врач (только анализ)
Локальный запуск (для разработки)
bash
# Установка зависимостей
pip install -e .

# Запуск API
python app.py

# В другом терминале запуск UI
streamlit run streamlit_app.py
📚 Документация
Подробная документация находится в папке docs/:

Документ	Описание
Установка и настройка	Подробная инструкция по установке
Архитектура системы	Описание архитектуры и компонентов
API эндпоинты	Документация по всем API-методам
Конфигурация	Настройка порогов, правил, алиасов
Клинические правила	Полный список диагнозов и комбинаций
🧪 Тестирование
bash
pytest -v
Интеграционные тесты покрывают загрузку конфигураций, комбинированные диагнозы, половые пороги и правила на основе диапазонов.
